How it works

One road, from first sight to offer.

Every application in Eregion travels the same five stations. The agent does the walking; you decide at the crossings.

  1. Sighted

    Searches job boards and company careers pages, builds a shortlist, and can run on a schedule.

  2. Prepared

    Scores each role against your resume, then drafts a tailored resume, cover letter and answers.

  3. Sent

    Opens the form in Chrome, fills what it knows, uploads approved files, and asks you for the rest.

  4. In interview

    Rehearses questions written for that job and that company, with feedback and a final report.

  5. Offer

    Your Road keeps the whole history, so you can see what worked.

Council

Know where you stand before you apply.

Paste a link or a job description. Eregion compares it with your resume and returns a score out of 100, the evidence behind it, the gaps, and the questions only you can answer.

  • Strengths and gaps cited from your own experience
  • Correct it, pause it, or take over its browser at any time
  • Keeps working on other tasks while it waits for you

The workspace

Named for the land of the elven-smiths.

Eregion was the realm where the great works were forged. Each part of the app takes a name from that world, and each does one job.

  • Chronicle

    Your home page. What happened today and what needs you.

  • Council

    Conversations with the agent, in folders, pinned or archived.

  • The Road

    Applications and their progress as a map, a board or a table.

  • The Forge

    Generated materials, versions, verification and approvals.

  • Job alerts

    Recurring searches and recommendation digests on your schedule.

  • The Lookout

    Live browser activity, with manual control when you want it.

Privacy and control

Your search stays on your machine.

Eregion is a local, single-user application. There is no Eregion account and no hosted service.

  • Local database

    Your resume, conversations, documents and application history are stored on your computer. The server listens on 127.0.0.1 only.

  • Your model, your key

    Bring any OpenAI-compatible provider that supports tool calling. Only the content a task needs is sent to the provider you configure.

  • You approve, it acts

    Approving materials and submitting an application are always explicit steps that you take.

  • Take the wheel

    Watch the agent's Chrome window, pause it, or take control when a site needs a login, MFA or a CAPTCHA.

Chrome extension

Bring a job in from any tab.

Eregion Lens opens in Chrome's side panel, extracts the posting on your current page, lets you correct it, and compares it with your saved resume. Save it, then continue in Eregion with materials, the application, or interview practice.

Chrome 116 or later. Included in the download, loaded as an unpacked extension.

Download

Set out in four steps.

About ten minutes, most of it waiting for packages to install.

Eregion for your computer

Source download from the main branch · includes the web app and Eregion Lens

Download .zip
Or clone with Git
git clone https://github.com/ethany14/Eregion-Agent.git

You will need

  • Python 3.12
  • Google Chrome for browser tasks
  • A model API key from an OpenAI-compatible provider with tool calling and structured output

  1. Unzip and open a terminal in the folder

    Or cd Eregion-Agent if you cloned it.

  2. Create an environment and install

    python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

  3. Connect your model

    Create a file named .env in the folder. Leave out LLM_BASE_URL if your provider uses the default endpoint.

    LLM_MODEL_ID=your-model-id
LLM_API_KEY=your-api-key
LLM_BASE_URL=https://your-provider.example/v1

  4. Start Eregion

    Then open localhost:8000/apply and upload your resume.

    python -m alembic upgrade head
python -m uvicorn eregion.api.main:app --host 127.0.0.1 --port 8000

Stuck? The user guide and configuration guide cover sign-ins, saved answers, alerts and recovery.

Good to know

Some sites need you
Login walls, unusual form widgets, MFA and CAPTCHA can pause the agent until you step in.
Scores describe evidence
A match score reflects what your resume shows. It is not a prediction of an employer's decision.
Review before you send
Generated materials are checked against their sources, and you should still read them before use.
Text PDFs only, for now
Resumes need selectable text. Run a scanned resume through text extraction first.
